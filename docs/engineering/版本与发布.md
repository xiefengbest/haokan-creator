# 版本与发布

## 版本号在哪

| 位置 | 说明 |
| --- | --- |
| **`pyproject.toml` → `version`** | 唯一权威；`creator` 与 `creator_publish.__version__` 自动读这里 |
| **Git commit** | `manifest.json` 的 `commit` / 安装包文件名 `haokan-creator-<commit>.tar.gz` |
| **国内 CDN** | https://hk-h5-cdn.levect.com/html/xiefeng/creator/dist/manifest.json |

对用户可说：**0.1.x**；对内排查用 **commit**。

## 每次改动能做 CLI 行为时（合并 / 交付前）

1. 在 **`CHANGELOG.md`** 写一条（按日期，一句话说明用户能感知的变化）。
2. 按改动幅度改 **`pyproject.toml` 的 `version`**：
   - 修 bug、小优化：**patch** +1（`0.1.1` → `0.1.2`）
   - 新命令或可感知能力：**minor** +1（`0.1.x` → `0.2.0`）
   - 破坏性变更：**major** +1（少见，需说明）
3. 只改文档 / 技能白话、不动运行时：`version` 可不变，仍建议更新 CHANGELOG「文档」类条目。
4. `python3 scripts/check_public_repo.py` 与 `python3 -m unittest discover -s tests` 通过。
5. push **haokan-creator** 后，在 **haokan-pm-demo** 跑：
   `bash 创作者平台/scripts/deploy-demo-to-oss.sh`
6. 需要时让运维刷新 CDN：`dist/manifest.json`、`dist/install-from-cdn.sh`、`dist/haokan-creator-<新commit>.tar.gz`、兼容别名 `dist/haokan-creator.tar.gz`（与当前包内容相同）。

## 用户如何更新（不连 GitHub）

```bash
curl -fsSL https://hk-h5-cdn.levect.com/html/xiefeng/creator/dist/install-from-cdn.sh | bash
```

脚本读 manifest，下载对应 `haokan-creator-<commit>.tar.gz`。
