# 作品排期与创建时间

## 字段含义

| 字段 | 含义 | CLI 行为 |
| --- | --- | --- |
| `startTime` / `endTime` | 预约上线时段（毫秒，上海时区语义） | `--start-date` 一天一张时：每天 `00:00:00`～`23:59:59` |
| 创建时间 | 作品入库时间 | **CLI 不传**；应由后端在 `releaseimage` 成功时写**服务器当前时间** |

## 已修复（CLI）

`creator work +publish --start-date` 与 `creator work +update --start-date` 会同时提交 `startTime` 与 `endTime`，与创作者后台「当天 00:00 至 23:59」一致。

## 待后端确认

若作品管理里「创建时间」显示为排期日起点，多半是后端把 `startTime` 当成了创建时间。期望：**创建时间 = 提交发布时间**，与 `startTime` 无关。

对已错误数据（如 1672340–1672344）可在后端订正创建时间，或由运营按作品 ID 手工改库（需服务端处理）。
