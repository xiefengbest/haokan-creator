仅需一行指令，在任意 Agent 发布创作者作品

安装 Haokan Creator，服务国内与海外创作者，在本机预览裁切并上传到订阅合辑。

复制以下命令到终端运行（macOS / Linux，需 Git 与 Python 3.9+）

git clone https://github.com/xiefengbest/haokan-creator.git ~/.haokan-creator/repo && bash ~/.haokan-creator/repo/install.sh

若提示找不到 creator：

export PATH="$HOME/.local/bin:$PATH"

安装包从 GitHub 拉取。clone 失败请联系谢峰获取离线包。默认国内线路；海外创作者在配置或添加账号时指定区域为 xjp（见安装指南）。

复制给 Cursor、Codex 等助手。Agent 按安装指南执行即可；约束与发布规则也在指南里。打不开 GitHub 时用「手动安装」。

帮我安装 Haokan Creator：https://github.com/xiefengbest/haokan-creator/blob/main/docs/安装指南.md
