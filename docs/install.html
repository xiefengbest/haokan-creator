Haokan Creator

好看云壁纸 · 创作者命令行

一行装好 creator，在本机预览、上传作品。本页可复制安装命令与 Agent 提示词；详细步骤仍见 GitHub 文档。

公开访问地址（可转发给编辑或贴进飞书）

https://xiefengbest.github.io/haokan-creator/install.html

在 macOS 或 Linux 终端粘贴并运行（需已安装 Git 与 Python 3.9+）：

安装
git clone https://github.com/xiefengbest/haokan-creator.git ~/.haokan-creator/repo && bash ~/.haokan-creator/repo/install.sh
若提示找不到 creator
export PATH="$HOME/.local/bin:$PATH"

整段复制给 Cursor、Codex、Claude Code 等代理，由它按页面与安装指南执行：

提示词
帮我安装 Haokan Creator。先打开 https://xiefengbest.github.io/haokan-creator/install.html 按步骤安装，并阅读 https://github.com/xiefengbest/haokan-creator/blob/main/docs/安装指南.md 完成配置。我还没有创作者账号、密码或签名密钥时，请提醒我联系谢峰申请，不要自己编造。我没明确说发布之前不要上传。

1导入签名密钥

向谢峰索取含 CREATOR_SIGN_KEY 的文件，执行 creator config import <文件路径>，再 creator config status（ready: true）。

2添加创作者账号

用 creator profile add 保存手机号与密码（不要写进配置文件）。

3验证登录

执行 creator auth status，返回 "ok": true 后再发布。日常用法见使用指南。
