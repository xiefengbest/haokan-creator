# 安装 Haokan Creator

**仅需一行指令，在任意 Agent 使用创作者命令行。**

- 手动安装：复制命令到终端
- 通过 AI Agent 安装：复制提示词给你的助手（Cursor、Claude Code、Codex、Trae 等）

详细步骤（给代理阅读）：https://github.com/xiefengbest/haokan-creator/blob/main/docs/安装指南.md

网页版（带复制按钮）：

- 公开地址：https://xiefengbest.github.io/haokan-creator/install.html
- 仓库内文件：[install.html](install.html)（推送到 `main` 后由 GitHub Pages 自动更新）

---

## 手动安装

复制下面这一行到终端运行即可完成安装：

```bash
git clone https://github.com/xiefengbest/haokan-creator.git ~/.haokan-creator/repo && bash ~/.haokan-creator/repo/install.sh
```

装好后重新打开终端，执行：

```bash
creator auth status
```

---

## 通过 AI Agent 安装

把下面**提示词**整段复制给你的 AI 助手，它会按安装指南自动完成安装：

```text
帮我安装 Haokan Creator：https://github.com/xiefengbest/haokan-creator/blob/main/docs/安装指南.md
```

如果还没有创作者账号、密码或密钥，请先联系谢峰申请。代理不要自己查找或编造。在用户明确说发布之前，不要上传。

---

## 装好之后

1. 联系谢峰申请账号、密码和后台配置，只写在本机
2. 用 `creator profile add` 保存创作者账号
3. 用 `creator auth status` 确认能登录
4. 日常用法见 [使用指南](使用指南.md)
