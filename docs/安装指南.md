# Haokan Creator 安装指南

下面的步骤写给代理执行。需要用户本人做的只有两件事：向谢峰申请账号、密码和密钥，以及在看到变动说明后明确同意。

网页地址：https://github.com/xiefengbest/haokan-creator/blob/main/docs/安装指南.md

## 开始之前

确认这台电脑有：

- Git
- Python 3.9 或更新版本
- macOS 或 Linux

在终端执行 `git --version` 和 `python3 --version`。缺哪一个，先让用户安装，再继续。

## 第 1 步：安装

```bash
git clone https://github.com/xiefengbest/haokan-creator.git ~/.haokan-creator/repo && bash ~/.haokan-creator/repo/install.sh
```

装好后，命令在 `creator`，代码在 `~/.haokan-creator/repo`，技能说明会接到这台电脑的代理目录。

重新打开终端。如果提示找不到 `creator`，先执行：

```bash
export PATH="$HOME/.local/bin:$PATH"
```

## 第 2 步：申请账号和密钥

账号、密码和密钥需要联系谢峰申请。还没有这些内容时停下来，请用户去申请。不要自己查找、编造，也不要从网页或仓库历史里抄。

用户拿到之后：

- 后台配置和密钥只写入 `~/.haokan-creator/repo/.env`。可以先复制同目录的 `.env.example`。不要提交这个文件，不要在对话里复述里面的内容。
- 创作者账号不要写进 `.env`，用下一步的命令保存在本机。

## 第 3 步：添加创作者账号

先执行下面的命令，不要加 `--yes`。它不会保存，也不会要求输入密码：

```bash
creator profile add --name 创作者名 --phone +8613800138000 --password-stdin
```

把退出码 `10` 里的基本信息和变动告诉用户。用户明确同意后，再请用户提供密码，用标准输入传入，并在命令末尾加上 `--yes`：

```bash
printf '%s' '用户提供的密码' | creator profile add --name 创作者名 --phone +8613800138000 --password-stdin --yes
```

密码不要出现在命令参数、技能说明、仓库或回复里。手机号换成用户实际拿到的号码。上面的号码只是格式示例。

一台电脑可以保存多个创作者号。以后要换默认号，先不加 `--yes` 执行 `creator profile use 创作者名`，用户同意后再加上 `--yes`。

## 第 4 步：确认能登录

```bash
creator auth status
```

成功时，输出里有 `"ok": true`，以及创作者名称和打过码的手机号。没有登录成功之前，不要发布作品。用户没明确说发布之前，不要上传。

## 下一步

阅读 [使用指南](使用指南.md)，按里面的说法把第一个发布任务交给代理：https://github.com/xiefengbest/haokan-creator/blob/main/docs/使用指南.md

发布时同时阅读 `~/.haokan-creator/repo/skills/creator-work/SKILL.md`。先预览，把基本信息和变动告诉用户，用户明确同意后才在命令末尾加上 `--yes`。

平时执行命令时，如果有新版本，会先自动更新再继续。正在发布时不会中途更新。也可以执行：

```bash
creator update
```

## 遇到这些问题

| 看到的情况 | 怎么处理 |
| --- | --- |
| 找不到 `creator` | 重新打开终端。仍找不到就执行上面的 `export PATH` |
| 提示还没有创作者账号，或还没有后台配置 | 请用户联系谢峰申请，不要继续猜 |
| 退出码是 `10` | 这是等待确认，不是失败。告诉用户基本信息和变动，同意后再加 `--yes` |
| 用户要新建合辑、删除作品或修改创作者资料 | 这些还没有开放。停下来说明，不要自己请求创作者接口 |
