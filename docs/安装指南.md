# Haokan Creator 安装指南

下面的步骤写给代理执行。需要用户本人做的只有两件事：向谢峰申请账号、密码和密钥，以及在看到变动说明后明确同意。

网页地址（国内 CDN，推荐）：https://hk-h5-cdn.levect.com/html/xiefeng/creator/docs/安装指南.md

（GitHub 镜像：https://github.com/xiefengbest/haokan-creator/blob/main/docs/安装指南.md）

## 代理须知

- 还没有账号、密码或签名密钥时，停下来请用户联系谢峰申请。不要自己查找、编造，也不要从网页或仓库历史里抄。
- 用户没明确说发布之前，不要上传。
- 增删改账号、合辑、作品、线上资料前，先把变动说明给用户，用户明确同意后再在命令末尾加 `--yes`。
- **已开放（用命令，勿手写接口）**：合辑查看/新建/改简介与频率/删除；作品发布/改描述与合辑与上线时间/删除；线上资料查看与修改。执行前读 `skills/creator-album`、`creator-work`、`creator-profile`。**仍未开放**：合辑封面与横滑封面、作品换图上传（去创作者后台）。

### 跟用户怎么说

安装与配置的对象是**编辑、运营**，不是工程师。对你这边的操作可以用命令和日志；**发给用户的话**只用白话，不要堆技术名词。

| 不要对用户这样说 | 可以这样说 |
| --- | --- |
| `ready: true`、`missingKeys: []`、`CREATOR_SIGN_KEY` 已写入 `backend.env`、权限 600 | 谢峰给的那份密钥已经在这台电脑上配好了，可以继续添加创作者账号。 |
| 先执行不带 `--yes` 的 `profile add`，退出码 `10` 表示等待确认 | 我先记下你的创作者昵称和手机号，请你核对一下；确认后我会再请你输入密码完成保存。密码请私聊发，不要在群里发。 |
| 用 `--password-stdin` 管道传入 | 我会用安全方式保存密码，不会在对话里复述。 |
| 「把密码发我，我用标准输入写入并加 `--yes`」「不会出现在命令行参数/日志/仓库」 | 见下方「添加账号·推荐话术」；整段禁止出现技术词。 |
| 复述密钥、签名或配置文件内容 | 一律不要。只告诉用户「已配置好」或「还缺什么（联系谢峰）」。 |

用户问「什么意思」时，用上面右边这种句子解释；只有用户明确要技术细节时，再补充命令名。

### 添加账号·推荐话术（用户已提供昵称和手机号后）

此时程序只是**核对信息，还没保存密码**，也还不能登录、不能发布。发给用户的话建议按这个结构写（可改昵称和尾号，不要抄技术步骤）：

```text
昵称和手机号我已经记下了，请您先核对是否无误：

· 创作者昵称：（用户提供的名称）
· 登录手机：尾号（后四位）

若没问题，请把创作者后台的登录密码发给我。建议在私聊里发，不要在群里发。收到后我会在这台电脑上完成保存，并帮您试一次能否登录。

说明：上一步还没写入密码，所以暂时还不能发布作品；保存成功之后就可以了。
```

用户不愿在对话里发密码时：说「可以。请您在本机终端里按安装指南完成保存，弄好后跟我说一声，我来帮您确认能否登录。」不要贴带密码的命令。

密码保存成功后对用户只说：**「账号已在这台电脑上保存好了，登录正常。」** 然后再执行 `creator auth status`（勿把 JSON 原文甩给用户）。

## 开始之前

确认这台电脑有：

- Git
- Python 3.9 或更新版本
- macOS 或 Linux

在终端执行 `git --version` 和 `python3 --version`。缺哪一个，先让用户安装，再继续。

## 第 1 步：安装

**国内网络（不需 GitHub）** — 优先用 CDN：

```bash
curl -fsSL https://hk-h5-cdn.levect.com/html/xiefeng/creator/dist/install-from-cdn.sh | bash
```

需要 Python 3.9+、`curl`、`tar`。更新版本时重新执行同一命令即可（安装脚本会先读 `dist/manifest.json`，再下载带提交号的 `haokan-creator-<commit>.tar.gz`，避免 CDN 缓存旧包）。

**可访问 GitHub 时**：

```bash
git clone https://github.com/xiefengbest/haokan-creator.git ~/.haokan-creator/repo && bash ~/.haokan-creator/repo/install.sh
```

若 `git clone` 失败，`install.sh` 会自动尝试从国内 CDN 下载；仍失败请联系谢峰获取离线包。

装好后，命令在 `creator`，代码在 `~/.haokan-creator/repo`，技能说明会接到这台电脑的代理目录。

重新打开终端。如果提示找不到 `creator`，先执行：

```bash
export PATH="$HOME/.local/bin:$PATH"
```

## 第 2 步：申请账号和密钥

账号、密码和密钥需要联系谢峰申请。还没有这些内容时停下来，请用户去申请。不要自己查找、编造，也不要从网页或仓库历史里抄。

用户拿到之后：

- 执行 `creator config import <谢峰提供的文件>`，或手动把文件放到 `~/.haokan-creator/backend.env`。不要自己逐项填写，不要提交 git，不要在对话里复述里面的内容。
- 执行 `creator config status`，确认显示后台配置已就绪。
- 创作者账号不要写进配置文件，用下一步的命令保存在本机。

## 第 3 步：添加创作者账号

**发给用户前**：先用人话完成「添加账号·推荐话术」里的核对与索取密码，再执行命令。不要在同一轮里对用户提 `--yes`、标准输入、退出码。

先执行下面的命令，不要加 `--yes`。它不会保存，也不会要求输入密码：

```bash
creator profile add --name 创作者名 --phone +8613800138000 --password-stdin
```

把退出码 `10` 里的基本信息和变动告诉用户。用户明确同意后，再请用户提供密码，用标准输入传入，并在命令末尾加上 `--yes`：

```bash
printf '%s' '用户提供的密码' | creator profile add --name 创作者名 --phone +8613800138000 --password-stdin --yes
```

密码不要出现在命令参数、技能说明、仓库或回复里。手机号换成用户实际拿到的号码。上面的号码只是格式示例。

**海外创作者**：在 `backend.env` 里写 `CREATOR_REGION=xjp`，或在添加账号时加上 `--region xjp`，例如：

```bash
printf '%s' '用户提供的密码' | creator profile add --name 创作者名 --phone +8613800138000 --password-stdin --region xjp --yes
```

一台电脑可以保存多个创作者号；不同号可以分别是国内或海外区域。以后要换默认号，先不加 `--yes` 执行 `creator profile use 创作者名`，用户同意后再加上 `--yes`。

## 第 4 步：确认能登录

```bash
creator auth status
```

成功时，输出里有 `"ok": true`，以及创作者名称和打过码的手机号。没有登录成功之前，不要发布作品。用户没明确说发布之前，不要上传。

## 下一步

阅读 [使用指南](使用指南.md)，按里面的说法把第一个发布任务交给代理：https://hk-h5-cdn.levect.com/html/xiefeng/creator/docs/使用指南.md

发布时同时阅读 `~/.haokan-creator/repo/skills/creator-work/SKILL.md`。先预览，把基本信息和变动告诉用户，用户明确同意后才在命令末尾加上 `--yes`。

**更新程序**：

- **国内 CDN 安装**（无 `.git`）：执行 `creator update`（会按 manifest 重新拉包），或再跑一遍 CDN 安装命令（见第 1 步）。
- **GitHub 安装**（有 `.git`）：执行 `creator update` 或 `git pull` 后重装依赖；平时跑命令时若检测到 GitHub 有新提交可能先自动拉取（发布进行中不会中途更新）。

## 遇到这些问题

| 看到的情况 | 怎么处理 |
| --- | --- |
| 找不到 `creator` | 重新打开终端。仍找不到就执行上面的 `export PATH` |
| 提示还没有创作者账号，或还没有后台配置 | 请用户联系谢峰申请，不要继续猜 |
| 退出码是 `10` | 这是等待确认，不是失败。告诉用户基本信息和变动，同意后再加 `--yes` |
| 用户要查看合辑、新建/改/删合辑、改/删作品、改线上资料 | 已支持。读对应 skill，先说明变动，用户同意后再加 `--yes`。对用户用白话，不要自编 API。 |
| 用户要改合辑封面、横滑封面，或只换作品图片不换文案 | 命令行不支持，请用户到创作者后台处理。 |
| `install.sh` 失败，日志里和 venv、`.pyc`、删文件有关 | 多是本机安全策略拦截，不是上次没删干净。先删掉 `~/.haokan-creator/repo/.venv` 再重跑脚本；仍失败就安装 [uv](https://github.com/astral-sh/uv) 后重跑。对用户说：「这台电脑限制比较严，我们换一种安装依赖的方式再试一次。」 |
| 打不开 GitHub、`git clone` 超时 | 用 CDN：`curl -fsSL https://hk-h5-cdn.levect.com/html/xiefeng/creator/dist/install-from-cdn.sh \| bash`。Agent 提示词改用 CDN 上的安装指南链接。 |
| `safe-delete`、`broker denied`、`egg-info`、WorkBuddy | **仅少数电脑**（企业文件代理/沙箱）会碰到。多数用户按第 1 步即可。若出现上述报错：请用户在 macOS「终端」里手动执行同一行命令，不要只在 WorkBuddy / 助手沙箱里跑；仍失败再装 uv 并重跑 `install.sh`。不要复述完整报错里的路径。 |
