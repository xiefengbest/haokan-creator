# 维护者：后台配置怎么发给编辑

编辑不用对着十几个 `CREATOR_*` 自己填。维护者通常只需要把 **`CREATOR_SIGN_KEY`** 发给对方；接口地址、STS、OSS 桶等已写在 CLI 内置默认值里（维护者本机仍可用环境变量覆盖）。

## 你要做的

1. 复制 [维护者-backend.env.example](维护者-backend.env.example) 为本地草稿（不要进 git）。
2. 填入 **`CREATOR_SIGN_KEY`**（向服务端申请或从现网配置读取）。海外创作者账号可加 `CREATOR_REGION=xjp`。
3. 通过安全渠道发给编辑，让对方执行：

```bash
creator config import <收到的文件路径>
```

也可以手动保存为 `~/.haokan-creator/backend.env`。

4. 让对方执行 `creator config status`，确认配置已就绪。
5. 单独发创作者账号和密码，让对方用 `creator profile add` 保存。不要把密码写进 `backend.env`。

## 编辑侧只需知道

- 安装命令行（见 [安装入口](安装入口.md)）
- 把收到的 `backend.env` 放到 `~/.haokan-creator/backend.env`
- 用 `creator profile add` 添加账号
- 用 `creator auth status` 确认能登录

## 可选

安装目录下的 `.env` 仍可写 `CREATOR_REGION`、`CREATOR_SQUARE_FROM` 等偏好项。已存在的变量不会被覆盖。
