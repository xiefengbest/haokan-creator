# 让代理帮你发布创作者作品

代理可以帮你整理图片、看预览、登录创作者后台，并把作品发到已经存在的合辑。图片从你这台电脑直接上传，不经过别人的服务器。

发布、添加账号、切换账号之前，代理会先告诉你基本信息和将要发生的变动。你明确同意之后，它才会执行。

网页地址：https://github.com/xiefengbest/haokan-creator/blob/main/docs/使用指南.md

安装步骤见 [安装入口](安装入口.md) 或 [安装指南](安装指南.md)

## 快速开始

### 1. 安装

把下面这句话贴给自己的代理：

```text
帮我安装 Haokan Creator：https://github.com/xiefengbest/haokan-creator/blob/main/docs/安装指南.md
```

装好后在对话里问「怎么配置账号和发布」即可。装好后重新打开终端和代理，让技能说明生效。

添加创作者账号时，助手应先让您核对昵称和手机号，再请私聊发登录密码；不要用「标准输入、--yes」等技术说法。若助手话说不明白，可看安装指南里的「添加账号·推荐话术」。

账号、密码和密钥需要联系谢峰申请。还没有这些配置时，代理应停下来请你申请，不要自己查找或编造。

### 2. 导入后台配置

谢峰发来那份密钥文件后，交给代理处理。你应该听到的是：**「已经在这台电脑配好了」**或**「还缺密钥，请联系谢峰」**——而不是一长串英文字段名或文件路径。

代理会在本机导入并自检；你不需要自己敲命令，也不要在群里粘贴密钥内容。

### 3. 确认能登录

代理执行：

```bash
creator auth status
```

输出里有 `"ok": true` 才算登录成功。没有登录成功之前，不要发布。

### 4. 发出第一个任务

打开代理的对话，用你自己的文件夹和合辑 ID 替换下面的内容：

```text
帮我把 ~/Downloads/图片文件夹 里的图片发到合辑 合辑ID。从 2026-07-13 起一天一张。先告诉我会发哪些、哪天可见。我同意之前不要上传。
```

代理应先给你预览。你同意后，它才真正上传。

## 可以这样用

### 把一个文件夹发到已有合辑

图片可以是 `1.jpg` 配 `1横图.jpg`，也可以每个子文件夹里放 `竖图.jpg` 和 `横图.jpg`。方图可以不放，默认从竖图正中间裁。竖图必须是竖的，横图必须是横的。

没写开始日期，就是立即发布。写了日期，就从那天 0 点起，按序号一天一张。

| 你可以这样说 | 代理应该怎么做 |
| --- | --- |
| 把这个文件夹发到合辑 123456，从下周一起一天一张。先让我看一遍。 | 先预览每张图的裁切结果和上线时间，等你明确同意后再上传 |
| 这些图今天就要可见。先告诉我有没有不能发的。 | 不写开始日期，预览通过后再等你同意。有不能发的图时，先让你处理，不要上传 |
| 新建一个叫「海边」的合辑，每天更新。先告诉我将创建什么。 | `creator album +create`，确认后再加 `--yes` |
| 把作品 987654 的描述改掉，或从合辑里删掉。 | `creator work +update` 或 `creator work +delete`，确认后再加 `--yes` |
| 改一下我的简介或社交链接。 | `creator me +show` 查看，`creator me +update` 修改，确认后再加 `--yes` |

同一文件夹、同一个合辑里已经发过的作品会跳过。

### 一台电脑使用多个创作者号

账号都保存在这台电脑上。某一次要换号，在命令前加上 `--profile 创作者名`，不会改掉默认号。从这台电脑删除登录信息，不会删除线上创作者。

| 你可以这样说 | 代理应该怎么做 |
| --- | --- |
| 我这台电脑上有哪些创作者号？ | 列出名称，让你选。有多个号又没说用哪一个时，不要擅自选第一个 |
| 以后都用「创作者名」这个号。 | 先告诉你将从哪个号换到哪个号，你同意后再切换 |
| 把「创作者名」从这台电脑去掉。 | 先说明只删除本机登录信息，你同意后再删除 |

## 现在能做的事

| 事项 | 能做的 |
| --- | --- |
| 后台配置 | 导入谢峰提供的 backend.env，检查是否齐全 |
| 账号 | 添加、查看、切换、从本机删除创作者号，并检查能否登录；支持国内与海外（`--region xjp`） |
| 合辑 | 查看列表；新建；改名称、简介、更新频率；删除（先确认再加 `--yes`） |
| 作品 | 预览文件夹并发布到合辑；改描述、所属合辑、上线时间；删除作品 |
| 线上资料 | 查看昵称、简介等；改昵称、简介、头像链接、一条社交链接 |
| 更新 | 平时自动更新命令和技能说明。正在发布时不会中途更换程序 |

合辑封面、横滑封面和作品换图还不能用命令行上传，需要到创作者后台处理。

## 常用命令

执行 `creator` 可以查看命令概览。

| 要做的事 | 命令 |
| --- | --- |
| 查看本机账号 | `creator profile list` |
| 添加账号 | 先不加 `--yes`。你同意后，密码从标准输入传入，再加 `--yes` |
| 切换默认账号 | `creator profile use 创作者名` |
| 只让这一次使用某个号 | `creator --profile 创作者名 auth status` |
| 检查能否登录 | `creator auth status` |
| 查看合辑 | `creator album list` |
| 新建合辑 | `creator album +create --name 名 --desc 简介 --frequency daily`（确认后加 `--yes`） |
| 预览发布 | `creator work +publish --dir 文件夹 --album-id 合辑ID --start-date 2026-07-13` |
| 确认后发布 | 在上一条命令末尾加上 `--yes` |
| 改/删作品 | `creator work +update` / `creator work +delete` |
| 改线上资料 | `creator me +show` / `creator me +update` |
| 更新 | `creator update` |

退出码 `10` 不是失败，是在等你确认。代理应把基本信息和变动告诉你，你明确同意后才能加上 `--yes`。

## 遇到这些问题

| 看到的情况 | 怎么处理 |
| --- | --- |
| 找不到 `creator` | 重新打开终端。仍找不到就执行 `export PATH="$HOME/.local/bin:$PATH"` |
| 提示还没有账号、密码或密钥 | 联系谢峰申请。不要把申请到的内容发进公开仓库或对话记录 |
| 有图片不能发布 | 先改图片或文件夹命名，再重新预览。不要在这一步上传 |
| 正在发布时提示有新版本 | 先看完这次发布结果，再执行 `creator update` |
