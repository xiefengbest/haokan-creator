# 创作者资料

先读 [creator-shared](../creator-shared/SKILL.md)。

修改头像、简介、社交链接还没有开放。本机账号的添加和切换用 `creator profile`，那只影响这台电脑用哪个号登录，不会改线上资料。

不要自己请求创作者接口去改资料。以后开放时，也要先给出基本信息和变动，用户确认后才执行。
